# QSAR_Modeling_for_Active_Dopamine_Receptor_D2_Inhibitors


This repository contains an end-to-end cheminformatics workflow designed to curate data from the ChEMBL database and train a Quantitative Structure-Activity Relationship (QSAR) regression model. The pipeline focuses specifically on active inhibitors ($IC_{50} < 1000\text{ nM}$) targeting the Human Dopamine Receptor D2 ($DRD_2$, ChEMBL ID: `CHEMBL217`) to optimize affinity prediction within high-potency chemical spaces.

---

## Dataset Summary

The compound library was dynamically mined from the ChEMBL database and subjected to rigorous data curation:
* **Target:** Human Dopamine Receptor D2 (`CHEMBL217`)
* **Activity Cutoff:** Strict inclusion threshold of $IC_{50} < 1000\text{ nM}$ (sub-micromolar inhibitors only).
* **Data Processing:** Nanomolar unit validation and multi-assay structural duplicate consensus averaging.
* **Final Saved Output Layout:** `SMILES`, `Name` (ChEMBL ID), and `pIC50` values.

---

## QSAR Modeling Workflow

The machine learning regression pipeline is structured sequentially across 8 modular phases:

### 1. Data Ingestion & Dataframe Initialization
The curated active compound dataset (`DRD2.csv`) is read into a structured Pandas dataframe. Missing values, structural duplicates, and faulty configurations are verified as clean before entering the featurization pipeline.

### 2. Fingerprint Calculator Configuration
Instead of manual string-parsing calculations, a structural fingerprint engine is initialized using the `molfeat` package. This abstract wrapper provides a high-level API to instantly configure classic molecular representations, such as Morgan/Circular (ECFP4/ECFP6) or path-based descriptors.

### 3. Molecule Transformer Instantiation
To handle batch conversions efficiently, a `molfeat` molecule transformer is initialized. This engine handles the underlying conversion of string tokens into high-dimensional vector representations natively optimized for linear algebra operations.

### 4. Molecular Featurization & Descriptor Generation
The transformer maps the raw input chemical structures (`SMILES`) into mathematical arrays. The resulting feature matrix ($X$) represents structural configurations, mapped directly against the target continuous vector ($y$) containing the transformed $pIC_{50}$ values.

### 5. Stratified Data Partitioning
The active compound matrix is split into independent training and test sets (e.g., an 80/20 division). This partitioning guarantees that model predictive behavior is validated against an entirely unseen chemical validation set, preventing data leakage.

### 6. Scikit-Learn Style Regressor Selection
An ensemble machine learning regressor (such as Random Forest, Gradient Boosting, or Support Vector Regression) conforming to the Scikit-Learn estimator framework is instantiated. These algorithms are ideal for processing sparse, bit-vector representations generated by molecular transformers.

### 7. Model Training & Performance Visualizations
The model is fitted onto the training partition. Model accuracy is systematically benchmarked across both splits using regression performance diagnostics:
* Coefficient of Determination ($R^2$)
* Mean Squared Error ($MSE$)
* Root Mean Squared Error ($RMSE$)
Actual vs. Predicted scatter plots are generated to analyze linear alignment across the active space.

### 8. Residual Error Analysis
Residual plots ($y_{\text{actual}} - y_{\text{predicted}}$) are plotted for both the training and testing datasets. This allows visual validation of homoscedasticity (even variance of error terms), catching potential systemic algorithmic bias within high-affinity compound boundaries.
